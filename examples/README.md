# 合成样本与保存结果

所有公开邮件均为合成研究数据。样本保留原文及对应保存分析；不代表真实消费者或市场排名。

| 目录 | 内容 | 用途 |
| --- | --- | --- |
| `research/emails` | 90 封模型生成的合成邮件 | 业务统计与原文回溯 |
| `research/analyses` | 对应 90 份保存分析，其中 87 份被接受 | 情绪、体验、意图及问题对象 |
| `research/historical80` | 历史模板邮件的 80 封子集、参考标签和原始/规范化预测 | 78/80、Macro-F1 及字段对照 |
| `research/calibration24.json` | 24 项有记录的分类确认 | 参考层次与交叉核对 |
| `replay/portfolio` | 作品集案例的保存来信、分析、回复和本地事件 | 当前工作台案例 |
| `replay/replays` | 5 份代表性历史保存回复，包括风险案例 | 当前审核规则回放 |
| `replay/portfolio-case-metrics.json` | 瑜伽垫精确版本人工评价与历史指标 | 回复对照及指标说明 |
| `replay/cohort-results.json` | 固定样本与新场景的保存结果分布 | 历史计数说明 |

历史 80 封来自较早的模板池；公开的是这 80 行，不将其说成完整 400 封都已公开。90 封与 80 封采用不同数据及评价来源，不能合并计算准确率。

保存分析和回复来自历史模型调用，自动评价是初步质量判断。人工参考、开发者辅助核查及精确版本人工裁决分别保留；这些材料不构成全量独立人工 Gold。瑜伽垫回复不改写，人工评价只对应对照页的原保存版本。

文件由已冻结作品集随附包中筛选导入。具体内容哈希见 docs/PUBLIC_FILES.json。为可移植运行，只调整公开数据的目录位置，原始邮件和回复正文不变。
