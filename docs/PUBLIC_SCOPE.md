# 公开源码与资产范围

本候选从原公开 main 的提交历史继续，纳入当前项目的全部 `src/` 应用模块、完整 React 源码、自动测试、可移植运行配置及经审查的合成演示输入。原开发工作区没有被切换、重置或清理。

## 纳入的工程能力

- FastAPI 路由、请求与会话校验、工作流接口。
- React 邮件工作台、分析依据、业务动作、版本记录、统计下钻及评价页面。
- LangChain / DeepSeek provider、结构化分析、输出工具、规划、事实校验及业务事件。
- 邮件、草稿、审核、知识与会话的 SQLite 持久化和幂等迁移。
- 分类、回复、风险、协议及实验完整性评价代码，以及相应离线 fake 和回归测试。
- 合成数据生成、验证、归一化、确定性统计与配置。
- 默认安全的离线入口、锁定依赖、CI 和源码范围审计工具。

公开默认入口复用实际业务模块，在临时存储中回放保存的合成案例。原 Streamlit 入口和其历史仍保留，模型接口及评测实现没有被替换成只供展示的假实现。

## 公开样本

`examples/` 是为离线运行明确筛选的输入集合，包含合成邮件、保存分析、保存回复、参考标签及必要的评价结果投影。其原始正文保持不变。历史 80 封参考、当前 90 封分析和精确版本人工判断分别标识，未合并为独立人工准确率。

`resources/p5a/` 保留项目自有的显式开发 fixture 和虚构知识资料，不能当成商家真实政策。

## 排除的资料

真实 `.env`、密钥、私人数据库、原始请求与预算账本、完整模型调用档案、学校非公开文件、论文与报告、个人目录、第三方 UI 参考图、字体和安装缓存均不公开。

历史文档导出、作品集排版、交付打包、资产清理及依赖私人机器的截图脚本不属于产品运行实现。它们保留在原本地工程与历史档案中。本候选保留对应业务、模型、评价和存储实现，并列明筛选结果。

旧的内部交接流水和原始研究附件从当前公开文件树移除，其已经公开的历史提交保留，不强制改写历史。
