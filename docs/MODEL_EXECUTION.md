# 模型调用与研究复现

`review.py` 是默认离线入口，强制关闭模型调用、LangSmith 和其他 tracing 开关。UI 的实时生成路由保持关闭。

完整模型实现位于 `src/infrastructure/structured_reply_provider.py`、`p5b8r3_execution.py`、`src/application/r6u0_workflow.py` 和 `service_response.py`。调用依赖明确的输入、配置、独立授权、请求上限及预算存储。API 密钥只从本地配置读取，真实 `.env` 不在仓库中。

历史实验的编排脚本保留其研究目的。原始预算账本、所有模型响应归档、人工私有档案与学校文档不公开，因此这些历史命令不是开箱即用的演示入口。不要重用关闭账本，也不要在原历史路径重新生成。新实验应配置新输出目录并独立记录输入和方案。

公开验证使用保存输出和离线 fake，能够检查结构化约束、统计成员、动作回执、草稿编辑、版本冲突、审核条件和风险阻断。它不会复现模型采样或证明新生成质量。
