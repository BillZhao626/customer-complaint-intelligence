# P4.7 研究者人工复核清单

以下由研究者亲自体验后填写。开发代理测试与合成预写内容不等于独立人工 Gold；建议每项记录会话、草稿版本及具体问题。未勾选表示待复核。

- [ ] 首次打开能看懂“收件箱 → 客户对话与回复 → AI Copilot”；研究工具不干扰客服主流程。检查桌面与窄屏，确认选中会话、原文、建议和编辑器一致。
- [ ] 体验普通咨询：回复承认未知规格，所问资料必要且不重复；轻确认后可模拟发送，修改草稿会使原批准失效。
- [ ] 体验配送受损、普通售后、多问题投诉：有合适的共情、事实确认与下一步，主要诉求均覆盖；已有编号不再索要，商家应核实的政策不转嫁给客户。
- [ ] 体验安全故障、强烈不满、退款/换货权限和“人工客服”：转交理由清楚，人工能接管并改稿；没有虚构真实坐席、已退款、已联系或已安排服务。
- [ ] 体验故意低估风险的旧坏例子：改写回复、问答或接管均不能解除分析阻断。正常安全案例仍要求核对停止使用、不复现故障及后续处理路径。
- [ ] 查看原文证据、版本/Diff、模拟回执和保存问答；刷新或重启后能恢复。理解离线预写、规则问答、历史重放与未启用真实调用的区别。
